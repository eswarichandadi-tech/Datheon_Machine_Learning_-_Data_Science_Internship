# Iris Flower Classification

## Internship
Machine Learning & Data Science Internship – Datheon

## Project Overview
This project implements supervised machine learning classification using the Iris dataset.

## Objectives
- Explore and understand the Iris dataset.
- Perform Exploratory Data Analysis (EDA).
- Apply feature scaling using StandardScaler.
- Split data into training and testing sets (80:20).
- Train Logistic Regression and Decision Tree classifiers.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Project File
`iris_classification.ipynb`

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open the notebook using Jupyter Notebook.
4. Execute all cells sequentially.

## Conclusion
This project demonstrates a complete supervised classification workflow, including data exploration, preprocessing, model training, and performance evaluation.
